Wispthe pocket follow drone

An open-source drone that knows where it is, avoids crashes and follows you while it films, built from proven parts so the work goes into flight software, control theory and follow-me.

Nothing has been built or flown. Phase 0 (research, parts, architecture and visual concepts) is waiting for the owner's review.
